
### Справочники

- ЕСКС (Единая система контекстных справок) — портал документации по инфраструктуре электронного правительства: СМЭВ, ЕИП НСУД, ЕСНСИ и ПО участников взаимодействия («Адаптер», «Агент», «Витрина», АРМ ДС). Есть разделы ГЭПС, ЕЛК, МФЦ и ФГИС ПГС на «ГосТех», поиск по документам. https://info.gosuslugi.ru/docs/
- Межведомственное электронное взаимодействие — раздел документации ЕСКС с регламентами, руководствами и формами заявок. В подразделе «ЕИП НСУД» опубликованы инструкции по получению доступа и работе с платформой. https://info.gosuslugi.ru/docs/section/СМЭВ/
- ПО для участников СМЭВ — каталог ЕСКС с дистрибутивами Адаптера СМЭВ3 и Агента СМЭВ4, образцами конфигурации Агента и списками изменений. Здесь же опубликованы руководства по установке и администрированию «Витрины данных», Агента проверок и АРМ Датастюарда. https://info.gosuslugi.ru/docs/section/ПО_для_СМЭВ/
- База знаний ЕСКС — каталог статей по системам электронного правительства с поиском. Материалы по СМЭВ собраны в разделе «Межведомственное информационное взаимодействие». https://info.gosuslugi.ru/materials/
- Prostore — справочник по ядру типового ПО витрин данных НСУД. Описывает развёртывание, подключение по JDBC и HTTP, управление схемой, загрузку и чтение данных, запросы SQL+. В редакции справочника от 08.09.2026 текущей указана версия 7.8.1. Доступен архив предыдущих версий. https://prostore.datamart.ru/docs_prostore/
