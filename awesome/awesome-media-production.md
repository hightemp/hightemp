# Медиа-производство

> Программное создание видео: video-as-code, графика, motion design, движки и пайплайны рендера.

### Видео как код; Программное создание видео

- Remotion — open-source фреймворк для программного создания видео из React-кода («видео как код»): компонент получает номер текущего кадра и холст, через `useCurrentFrame()`/`useVideoConfig()` описывается, что в каждом кадре; Composition задаёт width/height/fps/duration, результат рендерится в MP4. Встроенные компоненты для текста, изображений, видео, аудио и фигур; Remotion Studio — визуальный редактор с drag-and-drop, который пишет обратно в код (код всегда источник истины). Batch-рендер миллионов видео через шаблоны и параметры на своей инфраструктуре (server-side/client-side rendering), agentic создание через Agent Skills/Plugins (Claude Code и др.), Player для встраивания. Free для индивидуальных разработчиков и компаний до 3 человек, для больших — лицензия. TypeScript, активная разработка. https://remotion.dev https://github.com/remotion-dev/remotion
