# Neovim (nvim): шпаргалка по клавишам

Стандартные команды без плагинов. Если режим не указан, клавиши нажимаются в **Normal**. Пользовательский конфиг может переопределять сочетания.

**Обозначения:** `Ctrl-w` — удерживать Ctrl и нажать w; `g g` — нажать g дважды; `Ctrl-w h` — нажать Ctrl-w, отпустить, затем h. Команды с `:` вводятся с последующим `Enter`. Регистр важен: `w` и `W` — разные команды.

## Самое необходимое

| Клавиши | Действие |
| --- | --- |
| `Esc` | Вернуться из Insert/Visual в Normal |
| `i` | Начать ввод перед курсором |
| `:w` | Сохранить файл |
| `:q` | Закрыть текущее окно; последнее окно завершает nvim |
| `:wq` | Сохранить и закрыть окно |
| `:q!` | Закрыть окно без сохранения; буфер может остаться в других окнах |
| `:qa!` | Выйти, отбросив несохранённые изменения |
| `u` / `Ctrl-r` | Отменить / вернуть изменение |
| `:Tutor` | Открыть интерактивный учебник |
| `:help` / `:help {тема}` | Справка / справка по теме |

## Режимы и ввод

| Клавиши | Действие |
| --- | --- |
| `i` / `a` | Ввод перед / после курсора |
| `I` / `A` | Ввод перед первым непробельным символом / в конце строки |
| `o` / `O` | Создать строку ниже / выше и начать ввод |
| `v` / `V` / `Ctrl-v` | Выделение символов / строк / прямоугольного блока |
| `:` | Командная строка |
| `R` | Режим замены символов |
| `Ctrl-w` в Insert | Удалить слово перед курсором |
| `Ctrl-u` в Insert | Удалить введённый текст до начала строки; после перемещения курсора поведение ограничивается началом вставки |

## Перемещение

| Клавиши | Действие |
| --- | --- |
| `h` / `j` / `k` / `l` | Влево / вниз / вверх / вправо |
| `w` / `b` / `e` | Начало следующего / предыдущего слова / конец слова |
| `W` / `B` / `E` | То же для фрагментов, разделённых пробелами |
| `0` / `^` / `$` | Начало строки / первый непробельный символ / конец строки |
| `g g` / `G` | Начало / конец файла |
| `42G` / `:42` | Перейти на строку 42 |
| `Ctrl-d` / `Ctrl-u` | На полэкрана вниз / вверх |
| `Ctrl-f` / `Ctrl-b` | На экран вперёд / назад |
| `H` / `M` / `L` | Верх / середина / низ видимой области |
| `z z` / `z t` / `z b` | Расположить текущую строку по центру / сверху / снизу |
| `f{символ}` / `F{символ}` | Найти символ в строке вперёд / назад |
| `t{символ}` / `T{символ}` | Остановиться перед найденным символом вперёд / назад |
| `;` / `,` | Повторить поиск f/F/t/T в том же / обратном направлении |
| `%` | Перейти к парной скобке |
| `}` / `{` | Следующий / предыдущий абзац |
| `g j` / `g k` | Вниз / вверх по экранным строкам при переносе |
| `Ctrl-o` / `Ctrl-i` | Назад / вперёд по списку переходов |

Число перед командой повторяет её: `5j` — вниз на пять строк, `3w` — на три слова вперёд.

## Изменение, копирование и вставка

Удаление обычно помещает текст в регистр, откуда его можно вставить через `p`.

| Клавиши | Действие |
| --- | --- |
| `x` / `X` | Удалить символ под курсором / перед курсором |
| `r{символ}` | Заменить один символ |
| `d d` / `y y` | Удалить / скопировать строку |
| `3d d` / `3y y` | Удалить / скопировать три строки |
| `D` / `C` | Удалить / изменить текст до конца строки |
| `c c` | Изменить всю строку с переходом в Insert |
| `p` / `P` | Вставить после / перед курсором; строчный текст — ниже / выше строки |
| `J` | Объединить текущую и следующую строки |
| `.` | Повторить последнее изменение |
| `>` / `<` в Visual | Увеличить / уменьшить отступ выделения |
| `> >` / `< <` | Увеличить / уменьшить отступ строки |
| `= =` | Автоматически выровнять отступ текущей строки |
| `g g = G` | Выровнять отступы всего файла |
| `~` | Изменить регистр символа |
| `g u` / `g U` в Visual | Выделенный текст в нижний / верхний регистр |
| `Ctrl-a` / `Ctrl-x` | Увеличить / уменьшить число |

### Операторы и текстовые объекты

Формула: **оператор + перемещение или объект**. `d` удаляет, `c` изменяет с переходом в Insert, `y` копирует.

| Команда | Действие |
| --- | --- |
| `d w` | Удалить до начала следующего слова |
| `c i w` | Изменить слово целиком, находясь внутри него |
| `d a w` | Удалить слово с прилегающим пробелом |
| `y i w` | Скопировать слово целиком |
| `c i "` | Изменить содержимое двойных кавычек |
| `d i (` / `d a (` | Удалить содержимое круглых скобок / вместе со скобками |
| `c i {` | Изменить содержимое фигурных скобок |
| `v i p` | Выделить абзац |
| `y $` | Скопировать до конца строки |
| `d G` | Удалить от текущей строки до конца файла |

`i` означает «внутри», `a` — «вместе с окружением». Для Visual работают те же объекты: например, `v i "` выделяет содержимое кавычек.

## Поиск и замена

| Команда | Действие |
| --- | --- |
| `/текст` / `?текст` | Поиск вперёд / назад |
| `n` / `N` | Следующее совпадение по направлению поиска / в обратном направлении |
| `*` / `#` | Найти слово под курсором вперёд / назад |
| `:noh` | Убрать текущую подсветку результатов поиска |
| `:s/старое/новое/g` | Заменить все совпадения в текущей строке |
| `:%s/старое/новое/g` | Заменить все совпадения в файле |
| `:%s/старое/новое/gc` | То же с подтверждением каждой замены |
| `:10,20s/старое/новое/g` | Замена в строках 10–20 |

После выделения нажми `:`: диапазон `'<,'>` подставится автоматически. Команда `:'<,'>s/старое/новое/g` заменяет совпадения во всех строках выделения.

Поиск использует регулярные выражения. Для буквального поиска специальных символов начни шаблон с `\V`, например `/\Va.b`.

## Файлы и буферы

Буфер — открытый текст файла, окно — область его отображения, вкладка — набор окон.

| Команда | Действие |
| --- | --- |
| `:e путь/файл` | Открыть файл |
| `:w новое-имя` | Записать копию под другим именем |
| `:saveas новое-имя` | Сохранить под другим именем и переключиться на него |
| `:e!` | Перечитать файл, отбросив изменения буфера |
| `:ls` | Показать список буферов |
| `:bnext` / `:bprevious` | Следующий / предыдущий буфер |
| `:b 3` | Переключиться на буфер № 3 |
| `:b часть-имени` | Переключиться на буфер по имени |
| `Ctrl-^` | Переключиться на альтернативный буфер |
| `:bd` | Удалить текущий буфер из списка; несохранённые изменения требуют решения |
| `:wa` | Сохранить все изменённые буферы |
| `:Explore` | Открыть файловый обозреватель netrw, если штатный плагин включён |
| `g f` | Открыть файл, путь к которому находится под курсором |

## Окна и вкладки

| Команда | Действие |
| --- | --- |
| `:split` / `:vsplit` | Разделить окно по горизонтали / вертикали |
| `:sp файл` / `:vs файл` | Открыть файл в новом разделённом окне |
| `Ctrl-w h/j/k/l` | Перейти в окно слева / снизу / сверху / справа |
| `Ctrl-w w` | Перейти в следующее окно |
| `Ctrl-w =` | Выровнять размеры окон |
| `Ctrl-w +` / `Ctrl-w -` | Увеличить / уменьшить высоту окна |
| `Ctrl-w >` / `Ctrl-w <` | Увеличить / уменьшить ширину окна |
| `Ctrl-w o` | Оставить только текущее окно |
| `Ctrl-w c` | Закрыть текущее окно |
| `:tabnew` | Создать вкладку |
| `g t` / `g T` | Следующая / предыдущая вкладка |
| `2g t` | Перейти во вторую вкладку |
| `:tabclose` | Закрыть вкладку |

## Регистры и системный буфер обмена

| Клавиши | Действие |
| --- | --- |
| `"a y y` | Скопировать строку в регистр a |
| `"a p` | Вставить из регистра a |
| `"0 p` | Вставить последнее скопированное через yank, даже после удаления |
| `"_ d d` | Удалить строку, не меняя содержимое обычных регистров |
| `"+y` в Visual | Скопировать выделение в системный буфер обмена |
| `"+p` | Вставить из системного буфера обмена |
| `Ctrl-r +` в Insert | Вставить из системного буфера обмена при вводе |
| `:registers` | Показать содержимое регистров |

Системный буфер требует доступного clipboard-провайдера в окружении Neovim. Подробности: `:help clipboard`.

## Метки и макросы

| Клавиши | Действие |
| --- | --- |
| `m a` | Поставить локальную метку a |
| `'a` | Перейти на первый непробельный символ строки с меткой a |
| `` `a `` | Перейти к точной позиции метки a |
| `m A` | Поставить глобальную метку A для переходов между файлами |
| `q a` | Начать запись макроса в регистр a |
| `q` | Остановить запись макроса |
| `@a` / `@@` | Выполнить макрос a / последний выполненный макрос |
| `10@a` | Выполнить макрос a десять раз |

## Встроенный терминал

| Команда / клавиши | Действие |
| --- | --- |
| `:terminal` | Открыть терминал в текущем окне |
| `:split \| terminal` | Открыть терминал в горизонтальном разделении |
| `i` в терминальном буфере | Перейти к вводу команд в терминал |
| `Ctrl-\`, затем `Ctrl-n` | Выйти из Terminal-mode в Normal |
| `exit` в оболочке | Завершить оболочку терминала |

Для перехода из терминала в другое окно сначала нажми `Ctrl-\`, `Ctrl-n`, затем обычное `Ctrl-w h/j/k/l`.

## Справка и проверка сочетаний

| Команда | Действие |
| --- | --- |
| `:help usr_02` | Основы редактирования |
| `:help motion` | Перемещения |
| `:help text-objects` | Текстовые объекты |
| `:help windows` | Окна и буферы |
| `:help terminal` | Встроенный терминал |
| `:verbose nmap <клавиши>` | Проверить назначенный Normal-маппинг и источник настройки |
| `:verbose imap <клавиши>` | То же для Insert |

Назначения `<leader>`, файловые деревья, fuzzy finder и команды LSP зависят от конфигурации и плагинов. Их сочетания смотри в своём конфиге.
