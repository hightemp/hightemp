# TTT Editor: установка и шпаргалка по клавишам

## Установка

Команды выполняются в **оболочке терминала**. Выбери один способ установки. Ниже сочетания сверены с **TTT 1.11.0**, актуальным стабильным релизом на **10 ноября 2026 года**, по документации и стандартным назначениям в исходниках этого релиза.

### Linux

Официальный установщик скачивает готовый бинарник последнего релиза в `~/.local/bin`:

```bash
curl -sSfL https://raw.githubusercontent.com/eugenioenko/ttt/main/install.sh | sh
```

Если `ttt` не находится после установки, добавь каталог в `PATH` текущей оболочки:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Для постоянного действия добавь эту строку в файл запуска своей оболочки, например `~/.bashrc` для интерактивного Bash.

Установка в другой каталог:

```bash
curl -sSfL https://raw.githubusercontent.com/eugenioenko/ttt/main/install.sh | INSTALL_DIR="$HOME/bin" sh
```

`INSTALL_DIR` передаётся именно процессу `sh`, который запускает установщик. Выбранный каталог тоже должен находиться в `PATH`.

На Ubuntu/Debian дополнительные инструменты можно установить так:

```bash
sudo apt install curl git ripgrep
```

`curl` нужен для приведённой команды установки, Git — для работы с репозиториями, `ripgrep` (`rg`) — для поиска по проекту. Для простого редактирования уже установленному TTT Git и `rg` не обязательны. На Arch Linux доступна установка из AUR: `yay -S ttt`.

### macOS

При установленном Homebrew:

```bash
brew tap eugenioenko/ttt
brew trust eugenioenko/ttt
brew install ttt
```

Для Git-интеграции и поиска по проекту должны быть доступны `git` и `rg`; например, их можно установить через `brew install git ripgrep`.

### Windows

При установленном Scoop:

```powershell
scoop install ttt
```

Готовые бинарники, включая Windows ARM64, также доступны в [Releases](https://github.com/eugenioenko/ttt/releases). Скачай вариант для своей системы и архитектуры и помести его в каталог из `PATH`.

### Через Go

Нужен **Go 1.25 или новее**:

```bash
go install github.com/eugenioenko/ttt/cmd/ttt@latest
```

Для установки именно версии, по которой составлена шпаргалка:

```bash
go install github.com/eugenioenko/ttt/cmd/ttt@v1.11.0
```

Бинарник попадёт в `go env GOBIN`, а если значение пустое — в каталог `bin` внутри `go env GOPATH`, обычно `~/go/bin`. Этот каталог должен быть в `PATH`.

### Плагин Herdr

При установленном Herdr можно открывать TTT отдельной панелью рабочего пространства:

```bash
herdr plugin install eugenioenko/ttt/herdr-plugin
herdr plugin action invoke ttt.editor.open
```

Плагин устанавливает бинарник TTT, если не находит его в `PATH`. Эти команды относятся к Herdr; сочетания клавиш ниже — к самому редактору TTT. Подробности: [README плагина](https://github.com/eugenioenko/ttt/blob/v1.11.0/herdr-plugin/README.md).

### Проверка и обновление

```bash
ttt --version
ttt --help
```

При установке через `go install` команда `ttt --version` может показывать `dev`: в исходниках 1.11.0 это значение по умолчанию, а номер релиза в готовый бинарник добавляется при сборке. Версию Go-модуля можно проверить так:

```bash
go version -m "$(command -v ttt)"
```

Обновляй тем же способом, которым устанавливал: повторный запуск установщика, `brew upgrade ttt`, `scoop update ttt` или `go install github.com/eugenioenko/ttt/cmd/ttt@latest`. При обновлении версия может стать новее той, для которой проверены таблицы.

## Запуск

```bash
ttt                             # текущий каталог как проект
ttt .                           # то же явно
ttt ~/Projects/my-project       # открыть папку проекта
ttt src/main.go                 # открыть файл
ttt src/main.go:42:5            # открыть файл на строке 42, столбце 5
ttt dir1 dir2                   # несколько папок в одном workspace
ttt --workspace project.ttt     # открыть сохранённый workspace
ttt --welcome                   # стартовая страница без открытой папки
ttt --new-window src/main.go    # отдельный редактор при включённом reuseWindow
git diff | ttt                  # открыть вывод команды в несохранённой вкладке
```

Файл workspace `.ttt` сохраняется через **File → Save Workspace As...**. Открытие одного файла и открытие его папки — разные действия: для дерева проекта и поиска по нему удобнее запускать `ttt .` из корня проекта.

## Как читать сочетания

`Ctrl+K E` означает: нажать **Ctrl+K**, отпустить обе клавиши, затем нажать **E без Ctrl и Shift**. Аналогично `Ctrl+L F`: сначала Ctrl+L, затем обычная F. Заглавные буквы в обозначениях не требуют Shift, если он явно не указан.

`Ctrl+K S` и `Ctrl+K Ctrl+S` — разные последовательности. В стандартной конфигурации «Сохранить как» назначено на первую. `Ctrl+K 0` заканчивается цифрой **ноль**.

Обычный ввод текста не требует переключения в Insert, как в Vim. Таблицы рассчитаны на стандартные назначения без Vim/Emacs-плагинов. Если контекст не указан, подразумевается фокус в редакторе; в дереве, Git-панели, поле ввода и терминале обработка клавиш может отличаться.

| Клавиши | Действие |
| --- | --- |
| `Ctrl+P` | Открыть палитру команд |
| `Ctrl+K P` | Найти и открыть файл по имени |
| `Ctrl+O` | Открыть папку / workspace |
| `Ctrl+S` | Сохранить текущий файл |
| `Ctrl+F` | Найти в текущем файле |
| `Ctrl+K F` | Найти по проекту |
| `Ctrl+Z` / `Ctrl+Y` | Отменить / вернуть изменение |
| `Ctrl+B` | Показать / скрыть боковую панель |
| `Ctrl+T` | Показать / скрыть встроенный терминал |
| `Ctrl+W` | Закрыть вкладку |
| `Ctrl+Q` | Выйти из редактора |
| `Esc` | Закрыть всплывающее окно, убрать дополнительные курсоры или вернуть фокус в редактор — по текущему контексту |

В TTT **Ctrl+P открывает команды**, а **Ctrl+K P — поиск файлов**. В начальном приглашении палитры введи `?`, чтобы искать справку по интерфейсу и сочетаниям. Префикс `>` переключает палитру на команды.

## Несколько курсоров

| Клавиши | Действие |
| --- | --- |
| `Ctrl+D` | Выделить слово / добавить следующее совпадение слова или выделения |
| `Ctrl+K L` | Выделить все совпадения одновременно |
| `Alt+Shift+Up` / `Alt+Shift+Down` | Добавить курсор на экранной строке выше / ниже |
| `Alt+Click` | Добавить курсор в месте щелчка мышью |
| `Ctrl+K U` | Отменить последнее добавление курсора |
| `Esc` | Оставить один курсор |

Пример: поставь курсор на имя переменной, несколько раз нажми `Ctrl+D`, затем вводи замену. Это текстовое редактирование совпадений; для переименования символа с учётом языка используй **F2 через LSP**.

При переносе длинных строк `Alt+Shift+Up/Down` ориентируется на экранные строки, а не только на физические строки файла. Повторные нажатия расширяют набор курсоров в выбранную сторону.

### Файловое дерево

Сначала открой его через `Ctrl+K E`:

| Клавиши / действие | Действие |
| --- | --- |
| Стрелки / `Enter` | Навигация по дереву, раскрытие каталогов и открытие файлов |
| `r` / `R` | Обновить дерево |
| Правая кнопка мыши | Меню создания, переименования и удаления файлов и папок |

Чтобы найти текущий файл в дереве, выполни через палитру **Explorer: Reveal Active File**. При необходимости автоматического поиска файла включи `explorer.autoReveal` в настройках.

## Git: Changes

Нужен Git. Открой Changes через `Ctrl+K C`; следующие однобуквенные команды действуют **в дереве Git-панели**, а не в тексте файла или поле сообщения коммита.

| Клавиши | Действие |
| --- | --- |
| `Space` | Добавить выбранный файл в staged / убрать из staged |
| `a` / `A` | Добавить все unstaged-файлы в staged |
| `u` / `U` | Убрать staged-файлы из индекса |
| `r` / `R` | Обновить состояние |
| `Enter` | Открыть diff / активировать выбранный элемент |
| `d` | Отбросить unstaged-изменения выбранного файла с подтверждением |
| `Shift+D` | Отбросить все unstaged-изменения выбранной группы с подтверждением |

В поле сообщения коммита введи текст и нажми `Enter`, чтобы закоммитить staged-файлы. Pull/Push/Sync доступны из меню действий панели. При отбрасывании изменений untracked-файлы удаляются, а содержимое изменённых файлов восстанавливается — учитывай это перед подтверждением.

## LSP: навигация и работа с кодом

Нужен установленный и подключённый сервер языка. Подсветка синтаксиса сама по себе не означает, что работают переходы, переименование или форматирование. Наличие конкретного действия зависит от возможностей сервера; внешний форматтер настраивается отдельно.

| Клавиши | Действие |
| --- | --- |
| `Ctrl+U` | Вызвать автодополнение |
| `Ctrl+K I` | Показать документацию / hover под курсором |
| `F12` | Перейти к определению |
| `Shift+F12` / `Ctrl+L I` | Перейти к реализации |
| `Ctrl+L T` | Перейти к определению типа |
| `Ctrl+L R` | Найти использования символа |
| `F2` | Переименовать символ |
| `Ctrl+L F` | Отформатировать документ через LSP |
| `Ctrl+L E` | Отформатировать документ внешним форматтером |
| `Ctrl+L S` | Отформатировать выделение |
| `Ctrl+L O` | Упорядочить импорты |
| `Ctrl+L X` | Применить доступное действие Fix All |

Список проблем и результаты поиска использований доступны в нижней панели. Инструкции по серверам: [LSP для TTT 1.11.0](https://github.com/eugenioenko/ttt/blob/v1.11.0/docs-web/src/content/docs/guides/lsp.md).

## Встроенный терминал

| Клавиши | Действие |
| --- | --- |
| `Ctrl+T` | Показать / скрыть терминал в части окна |
| `Alt+T` | Переключить полноэкранное отображение терминала |
| `Ctrl+K T` при фокусе в редакторе | Создать новую терминальную вкладку |
| `Ctrl+V` при фокусе в терминале | Вставить из буфера обмена, если включено `terminal.ctrlVPastes` — по умолчанию да |
| `Shift+PageUp` / `Shift+PageDown` в терминале | Прокрутить историю на полэкрана |

**Когда фокус в терминале, большая часть клавиш уходит запущенной в нём программе.** Например, `Ctrl+C` прерывает команду оболочки. Если нужна команда редактора, сначала скрой терминал через `Ctrl+T`.

Чтобы передавать в терминальную программу сам `Ctrl+V`, отключи `terminal.ctrlVPastes`. Вставка через `Ctrl+Shift+V` доступна, если внешний терминал различает её с `Ctrl+V` или сам отправляет вставляемый текст.

## Настройка клавиш и конфликты с терминалом

| Клавиши | Действие |
| --- | --- |
| `Ctrl+K Y` | Открыть редактор назначений клавиш |
| `Ctrl+K ,` | Открыть настройки редактора |

В редакторе назначений доступны **Edit**, **Reset** и **Clear**: записать новое сочетание, вернуть стандартное или убрать назначение. Изменения сохраняются в `keybindings.json` и применяются сразу.

Пользовательские файлы в стандартном расположении:

- `~/.config/ttt/keybindings.json` — назначения клавиш;
- `~/.config/ttt/settings.json` — настройки редактора;
- `~/.config/ttt/themes/` — пользовательские темы.

Пример переопределений в `keybindings.json`:

```json
[
  { "key": "ctrl+k ctrl+s", "command": "file.saveAs" },
  { "key": "ctrl+shift+p", "command": "command.palette" }
]
```

Здесь «Сохранить как» использует **Ctrl+K, затем Ctrl+S**, а палитра — Ctrl+Shift+P. Если файл уже существует, добавляй записи в его текущий JSON-массив, сохраняя остальные назначения.

Если сочетание не работает:

1. Проверь фокус: редактор, дерево, поле поиска и встроенный терминал — разные контексты.
2. Для последовательности вроде `Ctrl+K E` отпускай Ctrl перед второй клавишей.
3. Открой нужную команду через `Ctrl+P` или меню. Если она выполняется оттуда, проверь назначение и перехват клавиш внешним терминалом, Herdr или оконным менеджером.
4. Особенно проверяй сочетания с `Alt`, `Ctrl+Shift` и функциональными клавишами: TTT получает только то, что передаёт терминал. При конфликте переназначь сочетание в одном из приложений.
